以下是专为AI辅助开发设计的**结构化任务大纲**，每个任务明确目标、输入输出和技术要点，方便AI理解并生成高质量代码：


## 【阶段1：项目初始化与基础配置】
### 任务1.1：搭建项目框架
- **目标**：创建基础小程序项目结构，配置云开发环境
- **输入**：微信开发者工具、小程序AppID
- **输出**：
  - 初始化项目文件夹（pages、cloudfunctions、utils等）
  - 配置project.config.json（指定云开发环境ID）
  - 初始化app.js/app.json（设置默认页面和窗口配置）
- **技术点**：
  - 使用微信开发者工具"云开发快速启动模板"
  - 配置云函数根目录："cloudfunctionRoot": "cloudfunctions/"

### 任务1.2：集成UI组件库
- **目标**：引入Vant Weapp组件库，确保基础样式统一
- **输入**：Vant Weapp官方文档
- **输出**：
  - 通过npm安装Vant Weapp并构建
  - 在app.json中全局注册常用组件（button、card、input等）
  - 新建theme.wxss统一主题色（主色：#36D399，辅助色：#3B82F6）
- **示例代码提示**：
  ```json
  // app.json中注册组件
  "usingComponents": {
    "van-button": "@vant/weapp/button/index",
    "van-card": "@vant/weapp/card/index"
  }
  ```

### 任务1.3：设计数据库结构
- **目标**：创建4个核心集合（表），定义字段和索引
- **输入**：核心业务实体（用户、任务、订单、消息）
- **输出**：
  1. users集合（用户表）：
     - _openid（主键）、role（身份：demander/tutor）、school（学校）、studentId（学号）、isVerified（认证状态）、tags（技能标签）、avatar（头像）
  2. tasks集合（任务表）：
     - _id、publisherId（发布者openid）、course（课程）、type（类型）、description（描述）、price（预算）、status（状态）、location（地点）、createTime（创建时间）
  3. orders集合（订单表）：
     - _id、taskId（关联任务）、tutorId（辅导者）、demanderId（需求方）、amount（金额）、commission（佣金）、isFree（是否免佣）、status（状态）、payTime（支付时间）
  4. messages集合（消息表）：
     - _id、fromId（发送者）、toId（接收者）、content（内容）、type（类型：text/image）、createTime（时间）、isRead（已读）
- **技术点**：为常用查询字段创建索引（如tasks.publisherId、orders.status）


## 【阶段2：用户系统开发】
### 任务2.1：登录与身份选择
- **目标**：实现微信快捷登录，支持身份切换
- **输入**：微信用户授权接口
- **输出**：
  - login页面：微信授权按钮，调用wx.getUserProfile获取用户信息
  - 身份选择页："我要找辅导"和"我要接单"两个按钮，点击后更新users集合的role字段
  - 自动跳转：已登录用户直接进入首页
- **核心代码提示**：
  ```javascript
  // 登录云函数
  exports.main = async (event, context) => {
    const { OPENID } = cloud.getWXContext()
    // 查询用户是否已存在，不存在则创建
    const user = await db.collection('users').where({ _openid: OPENID }).get()
    if (user.data.length === 0) {
      await db.collection('users').add({ data: { _openid: OPENID, role: '', isVerified: false } })
    }
    return { OPENID }
  }
  ```

### 任务2.2：校园认证功能
- **目标**：实现学号+校园卡认证，区分已认证/未认证用户
- **输入**：用户填写的学校、学号、上传的校园卡照片
- **输出**：
  - 认证表单页：包含学校选择器（预设本地大学列表）、学号输入框、图片上传组件
  - 认证状态展示：个人主页显示"已认证"标识，未认证用户发布/接单时提示认证
  - 审核逻辑：提交后isVerified设为"pending"，后期手动改为"true"（简化开发）
- **组件使用**：van-uploader（图片上传）、van-picker（学校选择）

### 任务2.3：个人主页开发
- **目标**：根据身份展示不同信息，支持基础操作
- **输入**：当前用户openid、users集合数据
- **输出**：
  - 需求方主页：我的发布（任务列表）、我的订单、钱包入口
  - 辅导者主页：技能标签编辑（最多5个）、服务记录（完成订单数）、资质上传区（3张图片）
  - 通用功能：头像昵称修改、身份切换按钮
- **UI参考**：顶部展示头像+昵称+学校，中部标签式展示不同模块


## 【阶段3：任务发布与接单系统】
### 任务3.1：任务发布页面
- **目标**：分步引导用户发布辅导需求
- **输入**：用户填写的任务信息
- **输出**：
  - 3步表单（用van-step组件）：
    1. 基础信息：课程名称（输入框+历史记录）、任务类型（单选：作业/论文/复习）
    2. 需求详情：文本描述（van-field）、上传图片（最多3张）、辅导方式（线上/线下）
    3. 时间预算：日期选择（van-datetime-picker）、预算金额（数字输入框）
  - 发布按钮：点击后调用云函数创建任务，状态设为"pending"
- **数据校验**：所有必填项未填时按钮禁用

### 任务3.2：任务列表与筛选
- **目标**：展示可接单任务，支持简单筛选
- **输入**：tasks集合数据（筛选status="pending"的任务）
- **输出**：
  - 任务列表页：
    - 顶部筛选栏：课程（最近/全部）、价格（低到高）、距离（仅线下）
    - 列表项：课程名称、预算、发布时间、距离标签（线下任务）
  - 下拉刷新/上拉加载：调用云函数分页获取数据
- **筛选逻辑**：通过云函数查询时添加where条件

### 任务3.3：接单与匹配功能
- **目标**：实现接单操作和需求方处理接单请求
- **输入**：辅导者的接单操作、需求方的确认/拒绝操作
- **输出**：
  - 任务详情页（辅导者视角）：任务信息+接单按钮，点击后提交接单理由
  - 接单管理页（需求方视角）：展示所有接该任务的辅导者列表，包含头像、标签、接单理由
  - 状态更新：需求方确认后，任务状态改为"confirmed"，创建初步订单
- **消息通知**：接单后给需求方发送模板消息


## 【阶段4：沟通系统开发】
### 任务4.1：聊天列表页面
- **目标**：展示与不同用户的聊天会话
- **输入**：messages集合数据（按会话分组）
- **输出**：
  - 会话列表：每个会话显示对方头像、昵称、最后一条消息、时间、未读红点
  - 点击跳转：进入与该用户的聊天详情页
- **数据处理**：按fromId+toId分组，取每组最新一条消息

### 任务4.2：聊天详情页面
- **目标**：实现基础聊天功能，支持价格确认
- **输入**：当前聊天对象openid、历史消息
- **输出**：
  - 聊天界面：顶部显示对方信息，中间消息列表（左对方右自己），底部输入框
  - 功能按钮：发送文字（van-field）、发送图片（van-uploader）、"确认价格"按钮
  - 价格确认：点击后弹出输入框，双方确认后生成正式订单
- **消息同步**：发送消息后存入messages集合，监听数据库变化刷新列表


## 【阶段5：交易与订单系统】
### 任务5.1：订单创建与支付
- **目标**：基于确认的价格创建订单，对接微信支付
- **输入**：任务ID、双方ID、确认的价格
- **输出**：
  - 订单确认页：展示任务信息、金额（含1%佣金）、实付金额
  - 支付按钮：调用微信支付API，支付成功后更新订单状态为"paid"
  - 免佣选项：若有免佣机会，显示"使用免佣"开关，佣金为0
- **支付流程**：
  1. 调用云函数创建预支付订单
  2. 获取prepay_id，调用wx.requestPayment
  3. 支付成功后触发回调，更新订单状态

### 任务5.2：订单管理页面
- **目标**：展示所有订单，支持状态筛选
- **输入**：orders集合数据（按当前用户ID查询）
- **输出**：
  - 订单列表：按状态分组（待支付/待辅导/已完成）
  - 订单项：任务名称、金额、状态标签、操作按钮
  - 操作逻辑：
    - 待支付：取消订单/继续支付
    - 待辅导：确认开始辅导
    - 已完成：确认结束（需求方点击后打款给辅导者）

### 任务5.3：佣金与结算逻辑
- **目标**：实现佣金计算和自动结算
- **输入**：订单金额、免佣状态、完成状态
- **输出**：
  - 佣金计算：订单金额×1%（免佣时为0）
  - 结算触发：需求方确认完成后，自动将（金额-佣金）转入辅导者余额
  - 余额展示：辅导者钱包页显示可提现金额，支持提现到微信
- **云函数逻辑**：
  ```javascript
  // 结算云函数
  if (order.status === 'completed') {
    const commission = order.isFree ? 0 : order.amount * 0.01
    const tutorIncome = order.amount - commission
    // 更新辅导者余额
    await db.collection('users').where({ _openid: order.tutorId }).update({
      data: { balance: db.command.inc(tutorIncome) }
    })
  }
  ```

### 任务6.1：推广中心页面
- **目标**：展示拉新任务和免佣权益
- **输入**：用户邀请记录、免佣机会数量
- **输出**：

    - 任务列表："邀请1人得1次免佣"、"邀请3人得3次免佣+5元"
    - 免佣记录：显示可用次数、过期时间
- **UI参考**：使用van-cell展示任务，进度条显示完成情况

### 任务6.2：邀请与免佣逻辑
- **目标**：实现邀请绑定和免佣权益发放
- **输入**：新用户注册时填写的邀请码
- **输出**：
  - 邀请绑定：新用户完成认证后，自动关联邀请者ID
  - 任务触发：邀请人数达标后，自动发放免佣机会到邀请者账户
  - 免佣使用：支付时选择使用，扣减次数，佣金设为0
- **数据存储**：新增invites集合记录邀请关系，freeCommissions集合记录免佣权益

### 给AI的提示：
1. 每个任务优先实现核心功能，再优化UI和交互
2. 云函数命名格式：功能+Action（如taskCreate、orderPay）
3. 复用组件：将按钮、卡片等封装为自定义组件，减少重复代码
4. 错误处理：所有API调用添加try/catch，显示友好提示（用van-toast）

按照这个大纲，AI可以分阶段生成代码，每个任务的输出都可独立运行并逐步拼接成完整项目，同时保证核心业务流程的完整性。
