# 📱 WeChat Mini Program | 微信小程序合集

> **Collection of WeChat Mini Program applications. Multiple mini-program projects with complete source code, including UI components, API integration, and common business scenarios.**
>
> 微信小程序应用合集。多个小程序项目完整源码，包含 UI 组件、API 集成和常见业务场景。

---

## 🌟 Features | 核心特性

- **Multiple Mini Programs** — Various application scenarios
- **WeChat API** — Native WeChat Mini Program API
- **UI Components** — Reusable component library
- **Cloud Integration** — WeChat Cloud Development support
- **Complete Source** — Full source code for each project

---

## 🚀 Quick Start | 快速开始

```bash
# Import into WeChat Developer Tools
# 1. Open 微信开发者工具
# 2. Import project folder
# 3. Select AppID (or use test account)
# 4. Compile and preview
```
