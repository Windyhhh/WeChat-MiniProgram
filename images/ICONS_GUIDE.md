# TabBar 图标说明

## 所需图标文件

项目需要以下8个图标文件用于底部导航栏：

### 1. 首页图标
- `home.png` - 首页未选中状态 (64x64px)
- `home-active.png` - 首页选中状态 (64x64px)

### 2. 任务图标  
- `task.png` - 任务未选中状态 (64x64px)
- `task-active.png` - 任务选中状态 (64x64px)

### 3. 消息图标
- `chat.png` - 消息未选中状态 (64x64px)  
- `chat-active.png` - 消息选中状态 (64x64px)

### 4. 个人中心图标
- `profile.png` - 个人中心未选中状态 (64x64px)
- `profile-active.png` - 个人中心选中状态 (64x64px)

## 图标设计要求

### 尺寸规范
- 推荐尺寸：64x64px (2倍图)
- 最小尺寸：32x32px (1倍图)
- 格式：PNG（支持透明背景）

### 设计风格
- **未选中状态**：灰色线条图标 (#7A7E83)
- **选中状态**：绿色填充图标 (#36D399)
- 风格：简约、现代、线条清晰
- 背景：透明

### 图标含义
1. **首页**：房子/主页图标
2. **任务**：文档/列表图标  
3. **消息**：聊天气泡图标
4. **个人中心**：用户头像图标

## 获取图标的方法

### 方法1：使用图标库
推荐使用以下图标库：
- **Iconfont (阿里巴巴矢量图标库)**: https://www.iconfont.cn/
- **Feather Icons**: https://feathericons.com/
- **Heroicons**: https://heroicons.com/

### 方法2：设计工具
- **Figma**: 免费的在线设计工具
- **Sketch**: Mac平台设计工具
- **Adobe Illustrator**: 专业矢量设计工具

### 方法3：在线图标生成器
- **Canva**: https://www.canva.com/
- **IconKitchen**: https://icon.kitchen/

## 临时解决方案

如果暂时无法获取图标，可以：

1. **使用纯色方块作为占位符**
2. **使用文字图标**
3. **暂时移除tabBar配置**

## 安装步骤

1. 将图标文件放入 `images/` 目录
2. 确保文件名与 `app.json` 中的配置一致
3. 重新编译小程序

## 注意事项

- 图标文件大小建议控制在10KB以内
- 确保图标在不同设备上显示清晰
- 遵循微信小程序的设计规范
- 建议提供2倍图以适配高分辨率屏幕
