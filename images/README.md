# 图片资源说明

这个目录包含小程序所需的图片资源。

## 需要的图片文件：

### 基础图标
- `logo.png` - 应用Logo
- `default-avatar.png` - 默认头像

### 轮播图
- `banner1.jpg` - 轮播图1
- `banner2.jpg` - 轮播图2  
- `banner3.jpg` - 轮播图3

### 装饰图片
- `login-decoration.png` - 登录页装饰图

### TabBar图标
- `home.png` / `home-active.png` - 首页图标
- `task.png` / `task-active.png` - 任务图标
- `chat.png` / `chat-active.png` - 消息图标
- `profile.png` / `profile-active.png` - 个人图标

## 图片规格建议：
- Logo: 200x200px
- 轮播图: 750x300px
- TabBar图标: 64x64px
- 默认头像: 200x200px

请将对应的图片文件放置在此目录下。
